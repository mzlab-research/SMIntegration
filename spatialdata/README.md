# Processed Data and Figure Mapping

This directory provides a mapping between the processed RDS data files used for benchmarking and the figures presented in the SMIntegration manuscript.

## Data Source
All processed data files are located in the `validation_figure/benchmarks/rds/` directory to maintain the integrity of the automated validation suite. A symbolic link (or reference) is provided here for convenience.

## How to Reproduce
The scripts to reproduce the figures (3-4) using the provided RDS data are located in `validation_figure/benchmarks/`. You can run `figure3.R` and `figure4.R` locally after setting the working directory to the project root.
