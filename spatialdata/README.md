# Processed Data and Figure Mapping

This directory provides a mapping between the processed RDS data files used for benchmarking and the figures presented in the SMIntegration manuscript.

## Data Directory
All processed and renamed data files for easy identification are located in the `spatialdata/data/` directory.

## How to Reproduce
The scripts to reproduce the figures (3-4) are located in `validation_figure/benchmarks/`. You can run `figure3.R` and `figure4.R` locally. Note that original scripts use the relative path `../../validation_figure/benchmarks/rds/`.
